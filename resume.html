설계 도면에서 검사 레시피를 생성하고, 현장 이미지로 정렬 마크 검출을 개선했습니다. 엔지니어의 주간 보고에는 로컬 언어 모델과 규칙 검사를 적용했습니다.

경력

일학습병행으로 입사해 국내 메모리 제조사 2곳의 양산 라인 셋업과 현장 대응을 맡았습니다. 2026년 상반기까지 설비 7종 이상, 작업 80건, 고객 문서 8건을 담당했습니다.

2022~2024년에는 검사 상태 화면, 불량 통계, 결함 좌표 매칭과 2D·3D 설비 셋업을 담당했습니다.

대표 프로젝트

  1. Shot Key 정렬 마크 검출 2026

    현장 정렬 시간 140초 → 23초, 12/12 슬롯 검출. 증강을 포함한 사내 영상 6,150장에서 CNN 오검출 280건 → 114건.

    템플릿을 규칙 검출로 바꾸고 촬영을 7줄에서 약 3줄로 줄였습니다. 규칙은 현장 검증 완료, CNN은 기존 판정과 병행 비교 중입니다.

  2. Feature 등록 없는 웨이퍼 정렬 2026

    합성 191건에서 오판정 통과 134→0건. 사내 48판정에서는 31→0건으로 줄고, 허용오차 안의 결과 보류는 0→10건으로 늘었습니다.

    Die 격자 주기와 여러 영역의 일치도로 각도를 구해 신뢰도가 낮으면 보류했습니다. C++ 이식과 사내 검증을 마치고 양산 전환을 검증 중입니다.

  3. Die 가장자리 Crack 검출 2026

    고객 시료의 검출 결과 1,883건 중 524건을 Die 가장자리 균열로 분류했습니다.

    가변 검사 띠와 마스크를 적용하고 대용량 영상을 나눠 보는 도구를 개발했습니다. 고객 시료로 균열과 모서리 깨짐 검출을 확인했습니다.

  1. 신규 Particle 제거 설비 SW 안정화 2025–2026

    11일(264시간) 관찰 중 고장 0건. 계획 중단 3시간을 포함한 비전 시스템 가동률은 98.86%였습니다.

    최신 프레임 표시, 카메라 재연결, 프로그램 종료 감지를 구현했습니다. 현장에 25일 상주해 정지를 재현·수정했습니다. 설비는 양산에 적용됐고 제3자 인증을 통과했습니다.

  2. Tip 파손 방지 인터록 2026

    양산 적용 후 팁 파손 재발 0건. 생산 로트가 정상 진행됐습니다.

    Z축 위치로 간섭을 확인하고 상승·정지가 끝나야 XY 이동을 허용했습니다. 별도 리프터 1,000회 시험으로 원점·리밋 센서에서 정지 위치 반복성(3σ)을 확인했습니다.

  3. 입자 높이 측정과 접촉 감지 2025

    영상 자동 초점 90초 → 25초. 접촉 방식은 300 µm 이상 입자에서 20회 측정 반복성 ±2 µm였습니다.

    무늬가 약한 바닥에서는 전압 신호로 바닥과 입자 윗면을 감지했습니다. 양산 자재의 연속·다중 전단 동작을 현장에서 검증했습니다.

  1. 도면 기반 검사 레시피 자동 생성 (RAC) 2026

    Bump 레시피 작성 4시간 → 20분, 대면적 도면 변환 314초 → 42초.

    도면 좌표를 보정해 Bump 약 25만 개를 배치하고 필요한 영역만 병렬 변환했습니다. 도면 변환은 양산 자재 검증을 통과했고, 통합 도구는 장비 투입 전입니다.

  2. Shot Key 검출 조건 학습과 CNN 검증 2026

    규칙 검출과 촬영 범위 축소로 현장 정렬 140초 → 23초, 12/12 슬롯 검출. 증강 포함 사내 영상 6,150장에서 CNN 오검출 280건 → 114건.

    같은 날의 영상이 학습·평가에 섞여 날짜별 고정 평가셋과 회귀 검사를 도입했습니다. 규칙은 현장 검증 완료, CNN은 기존 판정과 병행 비교 중입니다.

  3. 로컬 LLM 기반 주간 보고 자동화 2026

    공개 앱에서 두 주의 합성 자료로 비교한 결과, 보고서 내보내기 요청까지 입력 동작이 25회에서 16회로 줄었습니다.

    커밋을 주제별로 묶어 슬라이드를 작성하고, 수치와 상태 표현을 원문과 대조했습니다. 사내 도구는 팀원 10명이 사용했고, 한 주의 기록에서 직접 입력한 5개 주제의 보고서 생성을 확인했습니다.
