커밋에서 주간 보고 PPT 까지

git 커밋을 주제별로 묶고, 메모(왜 · 상태)를 보태 요약 3줄을 만든 뒤, 입력에 없는 숫자 · 상태어 · 효과어를 검사해 양식 PPT 로 내보냅니다.

  1. 1커밋 불러오기
  2. 2주제 · 메모 편집
  3. 3검증 · PPT 내보내기

저장소에서 아래 명령을 실행하고 결과를 붙여넣으세요. 내용은 이 브라우저 안에서만 처리되고, Claude 로 생성할 때만 해당 주제의 커밋 제목과 메모가 Anthropic API 로 전송됩니다.

git log --no-merges --date=short --name-only --since="5 weeks ago" --author="$(git config user.name)" --format="@@%h|%ad|%s"
영역(태그 · 구역) 규칙은 설정에서 저장소 폴더 구조에 맞게 고칠 수 있습니다.
